# Business Card Project

A simple and stylish **Business Card** built using HTML and CSS. This project demonstrates the fundamentals of web development, including HTML structure, CSS styling, layout design, and typography.

## ✨ Features

- Clean and minimal design
- Styled business card layout
- Custom colors, fonts, and spacing
- Organized HTML and CSS code
- Beginner-friendly project

## 🛠️ Technologies Used

- **HTML5** – Structure and content
- **CSS3** – Styling, layout, and visual design


## 🚀 Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.
3. Open `index.html` in your browser to view the business card.

Alternatively, use the **Live Server** extension in VS Code for a live preview.
